# Multispectral Water Body Segmentation Deployment

This repository contains the local deployment code for the **Pretrained ResNet-50 based U-Net** water segmentation model trained on 12-channel multispectral satellite imagery. 

The application packages the trained model into a locally running Flask web server with an interactive web UI. The server handles 12-channel TIFF file uploads, performs on-the-fly band normalization, and generates a side-by-side visualization showing a rendered visible-light (RGB) composite preview next to the predicted binary water mask.

---

## 1. Repository Structure

Organize your files in your local workspace exactly as shown below before pushing to your GitHub repository:

```directory
├── app.py                      # Main Flask server script (routes and web serving)

```

## 2. Prerequisites & Installation

### A. Set Up a Virtual Environment
It is highly recommended to isolate your dependencies inside a Python virtual environment:

```bash
# Create a virtual environment named 'venv'
python -m venv venv

# Activate the virtual environment
# On Windows:
venv\Scripts\activate
# On macOS / Linux:
source venv/bin/activate
```

### B. Install Dependencies
Install the required packages using the provided `requirements.txt`:

```bash
pip install -r requirements.txt
```

---

## 3. Running the Application

### A. Start the Flask Web Server
Execute the main application script:

```bash
python app.py
```

Upon execution, the model weights will be loaded into memory on your target device (defaults to CPU for general local compatibility):

```text
Loading pre-trained ResNet-50 model weights from best_unet_water_model.pth...
 * Serving Flask app 'app'
 * Debug mode: on
 * Running on http://127.0.0.1:5000
```

### B. Accessing the Web Interface
1. Open your web browser and navigate to: `http://127.0.0.1:5000`
2. Click the upload box and select a 12-channel multispectral `.tif` or `.tiff` file.
3. Click the **Segment Water Bodies** button.
4. The frontend will dynamically display:
   * **RGB Preview:** A visible-light rendering constructed on-the-fly from channels 3 (Red), 2 (Green), and 1 (Blue) of your TIFF.
   * **Predicted Water Mask:** The binary segmented output generated by the ResNet-50 U-Net network.

## 4. API Documentation

### `POST /predict`

Accepts a multipart form file upload containing a 12-channel TIFF image and returns both the predicted water mask and an RGB composite preview as Base64-encoded PNG strings.

* **URL:** `/predict`
* **Method:** `POST`
* **Content-Type:** `multipart/form-data`
* **Form Parameters:**
  * `file`: (Required) The 12-channel `.tif` or `.tiff` file.

* **Response (Success - 200 OK):**
  ```json
  {
    "success": true,
    "mask_image": "<Base64_Encoded_Mask_PNG_String>",
    "rgb_preview": "<Base64_Encoded_RGB_Composite_PNG_String>"
  }
  ```

* **Response (Error - 400 Bad Request or 500 Server Error):**
  ```json
  {
    "error": "Error details explaining the processing failure."
  }
  ```
